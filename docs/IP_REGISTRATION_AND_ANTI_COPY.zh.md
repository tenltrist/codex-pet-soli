# 朔璃 / Soli IP 登记与防抄袭行动指南

更新时间：2026-05-20  
说明：这份文档是实操清单，不是律师意见。真正提交前建议找熟悉版权/商标的律师或代理机构复核，尤其是 AI 辅助生成素材的权属表述。

## 1. 先区分三件事

### 版权 / 著作权

保护具体表达：角色原画、spritesheet、GIF、设定文、宣传图、视频、代码等。

重点：版权通常保护“作品表达”，不保护抽象想法。例如“月蚀魔女桌宠”这个概念本身不够，但 Soli 的具体造型、图像、动画、设定文字可以作为作品主张保护。

### 商标

保护商业识别：`朔璃`、`Soli`、`月蚀魔女·朔璃`、Logo、产品名等。

重点：别人如果做相似角色但不用你的名字，商标不一定管；别人如果用 Soli 名字卖桌宠、软件、周边，商标更有用。

### 证据链

证明你更早创作、持续迭代、公开发布、保留母版。

重点：证据链不是注册本身，但被抄袭时非常关键。

## 2. 现在立刻要做的 10 件事

1. 固定角色正式名称：**朔璃 / Soli**。
2. 固定一句话介绍：**Soli is an eclipse witch desktop companion for AI builders.**
3. 保存所有源文件、概念图、spritesheet、GIF、prompt、聊天记录、版本记录。
4. 给关键文件生成 SHA-256 哈希，当前已生成：`ip-evidence/soli-evidence-manifest.json`。
5. 写角色设定页：角色名、形态、颜色、性格、动作、禁用项。
6. 写版权声明：作者、年份、允许用途、禁止用途。
7. 做首次公开发布：GitHub Release / 个人站 / X / B站 / 小红书任选，但要留时间戳。
8. 在主要市场做商标近似检索：`朔璃`、`Soli`、`Soli Eclipse Witch`。
9. 先登记美术作品/视觉作品版权，再考虑软件著作权或应用商标。
10. 后续每个大版本都保留 changelog 和 hash manifest。

## 3. 中国大陆登记路线

### 3.1 版权登记

优先登记：

- 美术作品：Soli 角色原画、三形态概念图、发布封面。
- 类似摄制/视听或美术相关素材：GIF、动画预览、spritesheet 可按具体代理建议处理。
- 软件著作权：如果后续做独立桌面宠物应用，而不只是 Codex pet 资产包。

建议提交材料：

- 角色三视图或主视觉。
- 三形态 contact sheet。
- `spritesheet.webp/png`。
- 角色设定文档。
- 创作说明：说明用户审美选择、AI 辅助生成、人工筛选、编辑、修复、组合、命名、状态映射和最终定稿贡献。
- 创作过程证据：版本文件、聊天记录、哈希清单、发布时间戳。

注意：AI 辅助生成作品的登记和司法认定仍有不确定性。关键不是隐瞒 AI，而是清楚证明你的人工创作选择：角色定位、审美筛选、反差机制、命名、修改指令、取舍、裁切清理、动画状态映射、最终表达固定。

### 3.2 商标注册

优先注册标识：

- 中文：`朔璃`
- 英文：`Soli`
- 组合：`月蚀魔女·朔璃` 或 `Soli the Eclipse Witch`

建议优先类别：

| 类别 | 适用方向 | 优先级 |
|---|---|---:|
| 第 9 类 | 可下载软件、桌面宠物程序、数字图像/动画文件、计算机软件 | P0 |
| 第 41 类 | 娱乐服务、动画/视频内容、在线电子出版物 | P0 |
| 第 42 类 | SaaS、软件设计、AI 工具相关服务 | P1 |
| 第 16 类 | 贴纸、印刷品、设定集 | P1 |
| 第 25 类 | 服装周边 | P1 |
| 第 28 类 | 玩具、手办、玩偶 | P1 |

建议策略：先查近似，再按预算递进注册。`Soli` 可能近似风险比 `朔璃` 高，因为英文短词容易撞名；`朔璃`作为中文造词更可能有独占空间，但仍需检索。

## 4. 美国 / 国际路线

### 4.1 美国版权

如果要面向海外发布，可考虑在 U.S. Copyright Office 登记视觉艺术作品或软件/文字作品。美国版权局对含 AI 生成内容的作品有披露要求：只保护人类作者贡献的部分；AI 生成材料本身通常需要排除或说明。

实操建议：

- 不要声称“全部由人类手绘”，因为事实不符。
- 申请时重点描述人类贡献：角色概念、选择、编排、修改、状态映射、图像清理、spritesheet 组织、设定文。
- 对 AI 直接生成且没有足够人工修改的部分，按规则披露/排除。

### 4.2 美国商标

如果你计划在美国销售桌宠应用、数字资产或周边，可考虑向 USPTO 申请 `Soli` / `朔璃` / logo 商标。

重点：美国商标非常看重“实际商业使用”或“意图使用”。申请前要明确商品/服务类别、使用证据、展示页面、下载页、销售页。

### 4.3 国际商标

如果未来要做多国保护，可先在一个基础国家/地区申请，再考虑 WIPO Madrid System 做国际注册指定。商标是按国家/地区生效，不是注册一次全球自动保护。

## 5. 如果被抄袭，怎么处理

### 5.1 先取证，不要先吵

发现疑似抄袭后，先保存：

- 对方页面 URL。
- 页面截图/录屏，显示日期、账号、商品、价格、下载入口。
- 对方文件包、图像、视频、说明文。
- 平台店铺信息、订单信息。
- 和你作品的对比图。

严肃商业侵权建议做公证取证或找律师指导。

### 5.2 判断抄袭类型

| 类型 | 处理工具 |
|---|---|
| 直接盗用你的 spritesheet / GIF / 原图 | 版权投诉、平台 DMCA/侵权投诉、律师函 |
| 改色/裁切/轻微重绘 | 版权投诉 + 对比图，重点证明实质性相似 |
| 用 `Soli` / `朔璃` 名字卖货 | 商标投诉更强 |
| 做了相似“月蚀魔女桌宠”但视觉不同 | 可能较难，仅凭概念通常不够 |
| 用你的图训练/生成类似角色 | 看平台规则、license 禁止条款、证据难度较高 |

### 5.3 平台投诉材料模板

准备一个标准包：

```text
1. 权利人姓名/主体信息
2. 作品名称：朔璃 / Soli
3. 首次发布日期和链接
4. 权利证明：版权登记证 / 商标证 / 创作证据哈希 / 源文件
5. 被投诉链接
6. 侵权对比图
7. 要求：下架、停止售卖、停止使用 Soli 名称、删除盗用素材
8. 联系方式
```

### 5.4 什么时候升级到律师

- 对方商业规模较大。
- 对方注册了近似商标或抢注你的名字。
- 对方拒不下架。
- 平台投诉无效。
- 你准备索赔、发律师函或诉讼。

## 6. 对外授权建议

建议把 Soli 资产分成三层授权：

### A. 普通用户许可

允许：

- 个人安装使用。
- 录屏展示桌面。
- 非商业分享使用体验。

禁止：

- 二次售卖。
- 打包进其他软件或皮肤商店。
- 去除署名。
- 用作 NFT。
- 用作模型训练数据。
- 商业广告、直播打赏素材、商品周边，除非获得授权。

### B. 创作者二创许可

可以开放更宽松的 fan art，但要规定：

- 必须标注 `Soli / 朔璃` 原创角色归属。
- 禁止成人向、仇恨、政治、诈骗、冒充官方。
- 商用二创需要单独授权。

### C. 商业授权

对软件厂商、品牌联名、周边生产、平台发行，单独签授权协议。

## 10. 我的建议优先级

如果预算和精力有限，按这个顺序来：

1. **先公开发布 + 保存证据链**：最快建立时间戳。
2. **登记版权**：角色主视觉、spritesheet、设定文。
3. **检索并申请商标**：先 `朔璃`，再 `Soli`，优先第 9 / 41 类。
4. **做正式 release 包和 license**：让用户能用，但别人不能随便商用。
5. **等产品化后补软件著作权 / 海外商标**。

最关键判断：

> 版权保护 Soli 的具体样子和素材；商标保护 Soli 这个名字变成你的商业入口；证据链保护你在争议中能证明“这是我先做的”。
