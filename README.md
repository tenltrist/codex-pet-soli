# Soli / 朔璃 — Codex Desktop Pet

**Soli / 朔璃** is an eclipse witch desktop companion for AI builders.

She is quiet in idle, focused while Codex is working, and sharply expressive in high-energy reactions.

![Soli running preview](previews/running.gif)

## Install

Clone or download this repository, then copy the pet files into your Codex pet folder:

```bash
mkdir -p ~/.codex/pets/soli
cp assets/pet.json assets/spritesheet.webp ~/.codex/pets/soli/
```

Restart Codex or switch pets, then choose **朔璃 / Soli**.

You can also use:

```bash
bash scripts/install-local.sh
```

## Files

assets/pet.json          Codex pet config

## Character

Soli is built around an eclipse-state system:

- **Nocturne form**: quiet desktop presence.
- **Negative eclipse form**: focused work/review mode, holding a moon while Codex runs.
- **Blood moon form**: high-energy reactions.
