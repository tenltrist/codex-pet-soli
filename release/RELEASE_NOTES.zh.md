# Release 标题

朔璃 / Soli Eclipse Clean6 - Codex 桌面宠物首个公开版本

## 简介

朔璃 / Soli 是一只月蚀魔女桌宠：平时安静陪伴，Codex 工作时进入负片月蚀状态双手捧月，高能状态会切到更强烈的反差形态。

## 本版本内容

- Codex 兼容 `spritesheet.webp`
- `pet.json`
- 中英文 README
- 个人使用许可
- contact sheet
- 工作态 GIF 预览
- 文件哈希 manifest

## 安装

```bash
mkdir -p ~/.codex/pets/soli
cp pet.json spritesheet.webp ~/.codex/pets/soli/
```

然后重启 Codex 或切换宠物，选择 **朔璃 / Soli**。
