# 朔璃 / Soli — Codex 桌面宠物

**朔璃 / Soli** 是一只月蚀魔女桌宠：平时安静陪伴，Codex 工作时进入负片月蚀状态双手捧月，高能状态会切到更强烈的反差形态。

![Soli 工作态预览](previews/running.gif)

## 安装

下载本仓库后，把核心文件复制到 Codex pet 目录：

```bash
mkdir -p ~/.codex/pets/soli
cp assets/pet.json assets/spritesheet.webp ~/.codex/pets/soli/
```

然后重启 Codex 或切换宠物，选择 **朔璃 / Soli**。

也可以直接运行：

```bash
bash scripts/install-local.sh
```

## 文件结构

```text
assets/pet.json          Codex 宠物配置
assets/spritesheet.webp  8×9 图集，单格 192×208
assets/contact-sheet.png 状态总览
previews/*.gif           动作预览
docs/                    创作流程与 IP 保护文档
release/*.zip            可分享发布包
```

## 角色设定

Soli 的核心是“月蚀状态系统”：

- **极夜形态**：日常安静陪伴。
- **负片月蚀形态**：工作/审查模式，Codex 运行时双手捧月。
- **血月形态**：高能反应，反差更强。
